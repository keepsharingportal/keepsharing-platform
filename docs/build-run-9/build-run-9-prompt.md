```markdown
# The 23 Point Proven Ad Formula
## KeepSharing's Marketing Science

**Never forget:**
> "People Don't Come Here For The Ads, So The Ads Must Be Exceptional At Getting The Attention of the Preferred Prospect and Inspiring Them to Take Action."
> 
> "We aspire that every ad we create for our clients produces sales, not compliments."

---

## 1. HEADLINE: The Most Important Piece (Up to 50% of Effort)

Headlines (and images) are how we know what to read or skip over. Put the one thing most important to your prospect in the place they're most likely to see it.

### 1a. Headlines Select the Audience
Write a NICHE headline (never generic) in the preferred prospect's own language that flags down the preferred prospect and ignores everyone else.

### 1b. Offer a Reward
Feature the advertiser's biggest psychological benefit:
- Better Health
- More Money
- Comfort
- More Time
- Praise From Others
- Security
- Social Advancement
- Better Appearance
- Increased Enjoyment

### 1c. Make It Emotional
**FEAR is #1.** Other emotional triggers:
- Failure / Embarrassment
- Hate
- Love
- Family
- Peace / Fulfillment
- Freedom
- Pride
- Vanity

### 1d. Use Title Case and quotations as much as possible.

### 1e. Use Headline Swipe Files to inspire your headlines.

## 2. LEAD: Hold Their Attention Once You've Got It

Write a Lead Sentence or Paragraph that holds attention.

### 2a. Entice Them Further
Highlight major advantages of the product or service in a short, easy-to-read sentence or two answering the "reward-promise" you made in the headline.

### 2b. Is "YOU" in the First Few Words?
It's always about the prospect. Talk about them, not your business.

## 3. BODY: Use Bullet Points to Arouse Curiosity, Build Sales Pressure, Stimulate Interest

### 3a. Write How the Product or Service Benefits the Reader
Not features. Benefits.

### 3b. Use the "Feature + Benefit = Meaning" Formula
What does the feature do for the buyer? What does that benefit MEAN to them?

### 3c. Use 3-6 Bullets
Not more. Not less.

## 4. PROOF: Back Up Your Promise

Emotion captured their attention. Now they need justification — a good excuse to buy.

- Quality or Reputation (Trusted for 20 yrs)
- Achievements (Over 10K sold)
- Testimony of users (Reviews)
- Expert evidence
- A guarantee

## 5. CLOSE: Offer a Strong Closing to the Biggest Critic

### 5a. Restate the Promise
Usually the close is about the same promise as your headline.

### 5b. Make It Bold
Push them over the fence.

### 5c. Showcase Positive AND Negative Effects
What happens if they DON'T act? They must see it in their mind before they act. Give them an incentive.

## 6. ACTION: Always Ask for the Click

What a shame to get attention, excite, make an offer, prove it — and then not ask the reader to do anything.

### 6a. What Do You Want People to Do?
Define this BEFORE writing.

### 6b. Stronger CTAs for Direct Response
Larger companies might do "Brand" advertisements. Smaller businesses (with much less money) need DIRECT advertisements with strong CTAs.

### 6c. Types of CTAs
- Make an Offer
- Give a Time Limit
- Limited Supply
- Price Change
- Stress what the reader stands to Gain or Lose
- Product Guarantee

### 6d. Make It Easy, Simple, Specific
"Text this number"
"Today, By Jan 20th"

### 6e. Include All Contact Details Needed

## 7. PICTURES

### 7a. ONE Large Photo > Several Small Photos
One large photo gets more attention.

### 7b. Show Product in Use
When possible.

### 7c. Show People in Active Situations
Not posed.

## 8. LAYOUT

### 8a. Make It Interesting
Powerful, unusual, or even very simple.

### 8b. Show Movement and Flow
Less symmetrical.

### 8c. Use Subheads to Break Up Long Copy

### 8d. Enough White Space?

### 8e. Typically Use Only 2-3 Fonts

### 8f. Include Logo
```

### 6A — Build `/src/lib/copy-validator.ts`

Validates partner copy against the 23 Points formula:

```typescript
export interface ValidationResult {
  field: string;
  passed: boolean;
  warnings: string[];
  suggestions: string[];
  score: number; // 0-100
}

export function validateHeadline(text: string, category: string): ValidationResult {
  const warnings = [];
  const suggestions = [];
  let score = 100;
  
  // Check for emotional language (fear, love, family, freedom, peace, security, vanity, pride)
  const emotionalWords = ['fear', 'stress', 'worry', 'anxious', 'love', 'family', 'safe', 'free', 'peace', 'pride', 'best', 'trusted', 'proven'];
  const hasEmotion = emotionalWords.some(w => text.toLowerCase().includes(w));
  if (!hasEmotion) {
    warnings.push('Headline lacks emotional language. FEAR is the #1 emotional trigger in advertising.');
    suggestions.push('Try adding words that speak to fear, love, family, or peace.');
    score -= 25;
  }
  
  // Check for niche specificity
  const isGeneric = ['business', 'company', 'practice', 'service'].some(g => text.toLowerCase().split(' ').filter(w => w === g).length > 0) && text.length < 30;
  if (isGeneric) {
    warnings.push('Headline is too generic. Speak in your prospect''s language.');
    suggestions.push('Mention "your child", "your family", or a specific concern your prospects have.');
    score -= 20;
  }
  
  // Check for benefit/reward
  const benefitWords = ['stress-free', 'free', 'save', 'win', 'love', 'best', 'better'];
  const hasBenefit = benefitWords.some(w => text.toLowerCase().includes(w));
  if (!hasBenefit) {
    warnings.push('Headline doesn''t feature a clear reward or benefit.');
    suggestions.push('Lead with what your prospect WINS. Better health? Save time? Stress relief?');
    score -= 15;
  }
  
  return {
    field: 'headline',
    passed: score >= 70,
    warnings,
    suggestions,
    score
  };
}

export function validateLead(text: string): ValidationResult {
  const warnings = [];
  const suggestions = [];
  let score = 100;
  
  // Rule 2b: "you" should appear in first few words
  const firstWords = text.split(' ').slice(0, 5).join(' ').toLowerCase();
  if (!firstWords.includes('you') && !firstWords.includes('your')) {
    warnings.push('Your lead doesn''t start with "you". The reader needs to feel like the message is FOR them.');
    suggestions.push('Rewrite to start with "You" or "Your".');
    score -= 30;
  }
  
  // Rule: leads should be tight, not rambling
  if (text.length > 200) {
    warnings.push('Lead is too long. Keep it short and punchy.');
    suggestions.push('Aim for 1-2 sentences, under 150 characters.');
    score -= 20;
  }
  
  return {
    field: 'lead',
    passed: score >= 70,
    warnings,
    suggestions,
    score
  };
}

export function validateBullets(bullets: string[]): ValidationResult {
  const warnings = [];
  const suggestions = [];
  let score = 100;
  
  // Rule 3c: 3-6 bullets
  if (bullets.length < 3) {
    warnings.push('You have fewer than 3 bullet points. The formula recommends 3-6.');
    suggestions.push('Add at least one more benefit point.');
    score -= 30;
  } else if (bullets.length > 6) {
    warnings.push('You have more than 6 bullet points. Too many dilute attention.');
    suggestions.push('Cut to your strongest 4-6 points.');
    score -= 15;
  }
  
  return {
    field: 'bullets',
    passed: score >= 70,
    warnings,
    suggestions,
    score
  };
}
```
